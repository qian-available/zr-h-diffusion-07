## 2. 研究目标与极简路线

本阶段保留三个核心目标：

1. 获得一致能量定义下的 `E(Zr96)`、`E(H2)`、`E[Zr96H(T)]` 和 `E[Zr96H(O)]`；
2. 判断 T/O 初始位在弛豫后是否仍是彼此独立的局域稳态，并计算实际稳定构型的 H 溶解能；
3. 在选定稳定位基础上，后续计算基面内和 c 轴方向的普通 NEB 扩散势垒。

一句话路线为：

```text
继承 450 eV + 5x5x4
  -> Zr96 static、H2 relax、T/O relax
  -> 核验真实稳定位
  -> 弛豫基面内与 c 轴等价终点
  -> 两条 4 中间图像普通 NEB
  -> 提取溶解能与扩散势垒
```

为降低上手成本，本路线明确不做 Zr2 跨平台复现、`3x3x2`/`4x4x3` 粗筛、450/500 eV
对照、relax 后 matching static、6 图像对照、有限尺寸测试或 CI-NEB。因而最终结果必须注明：
固定参数继承自纯 Zr 收敛结果，并不等于已经完成 Zr-H 参数、有限尺寸或精确鞍点收敛。

## 3. 结构与计算输入

### 3.1 结构来源

Zr96 来自已经复核的两原子 HCP Zr 弛豫结构，经 `4x4x3` 扩胞得到 96 个 Zr。母结构基线为：

```text
a = 3.23415635 A
c = 5.16602148 A
c/a = 1.59733202
```

Zr96 超胞晶格矢量为：

```text
  6.4683126953  -11.2034462276   0.0000000000
  6.4683126953   11.2034462276   0.0000000000
  0.0000000000    0.0000000000  15.4980644252
```

四个初始结构如下：

| 目录 | 体系 | 原子数 | 初始 H 信息 |
| --- | --- | ---: | --- |
| `01_zr96_static` | Zr96 | 96 | 无 H |
| `02_h2_relax` | 15 A 立方盒中的 H2 | 2 | 初始键长 0.75 A |
| `03_t_relax` | Zr96H | 97 | 初始分数坐标约 `(1/3, 5/12, 13/24)` |
| `04_o_relax` | Zr96H | 97 | 初始分数坐标 `(1/2, 1/2, 1/2)` |

T/O 的上述坐标只是初始构型定义。只有弛豫完成并分析 `CONTCAR` 后，才能判断 H 是否仍
属于原位点族；不能由目录名直接认定最终构型仍是 T 位或 O 位。

### 3.2 共同设置与差异

| 设置 | Zr96 static | H2 relax | T/O relax |
| --- | --- | --- | --- |
| `ENCUT` | 450 eV | 450 eV | 450 eV |
| `PREC` | Accurate | Accurate | Accurate |
| `EDIFF` | `1E-7` | `1E-8` | `1E-7` |
| 展宽 | `ISMEAR=1`, `SIGMA=0.20` | `ISMEAR=0`, `SIGMA=0.05` | `ISMEAR=1`, `SIGMA=0.20` |
| k 点 | Gamma `5x5x4` | Gamma `1x1x1` | Gamma `5x5x4` |
| 离子运动 | `NSW=0` | `IBRION=2`, `NSW=100` | `IBRION=2`, `NSW=200` |
| 力阈值 | 不适用 | `EDIFFG=-0.005 eV/A` | `EDIFFG=-0.01 eV/A` |
| 晶格 | 固定 | 固定盒子 | `ISIF=2`，固定晶格 |
| 对称性 | `ISYM=2` | `ISYM=0` | `ISYM=0` |
| 投影 | `LREAL=.FALSE.` | `LREAL=.FALSE.` | `LREAL=.FALSE.` |

所有任务均从头启动：`ISTART=0`、`ICHARG=2`；使用 `ALGO=Normal`、`NELM=160`，并关闭
WAVECAR/CHGCAR 的常规写出。

### 3.3 `5x5x4` 的来源与边界

纯 Zr 两原子原胞已经用 `KSPACING=0.12 A^-1` 做过保守精度计算。扩成 `4x4x3` 超胞后，
倒易晶格在对应方向缩小，保持近似相同 k 点密度时，各方向网格数随扩胞倍数反向缩放；
结合该实际非正交 HCP 晶胞的网格取整，映射约为 `5x5x4`。

这是一种从纯 Zr结果继承的等密度映射，不是本次对 Zr96H 重新完成的 k 点收敛测试。
`5x5x4` 有 100 个全网格点；T/O 使用 `ISYM=0`，空间对称性不能像纯 Zr 中那样显著减少
计算量。实际参与计算的 `NKPTS` 应在任务结束后从各自 `OUTCAR` 读取。

## 8. 大框警告与运行速度分析

### 8.1 两个大框不是报错

VASP 打印了两类建议：

1. 建议设置 `NCORE=2` 到每插槽核心数范围；
2. 对大超胞建议尝试 `LREAL=Auto`。

这两段分别是并行性能和实空间投影建议。随后程序成功读取 97 个原子，确认输入无误并进入
`DAV` 主循环，因此它们不是计算失败信息。

`LDA part: xc-table for Pade...` 也是 VASP 初始化交换关联表的常见内部信息，不能据此认定
本任务错误使用了 LDA；正式势的 `TITEL` 和数据血缘均为 PAW_PBE。

### 8.2 为什么 T/O 明显比 H2 和纯 Zr慢

主要成本来自以下因素共同作用：

- 原子数从 H2 的 2 个增至 97 个，平面波、能带和电荷密度规模大幅增加；
- H2 只有 Gamma 点，而 Zr96H 使用 `5x5x4`；
- T/O 设置 `ISYM=0`，不能利用纯 Zr 完美晶体的空间对称性大量缩减 k 点；
- `LREAL=.FALSE.` 使用倒空间投影，精度保守但对大超胞更昂贵；
- 输出显示 `distrk: each k-point on 32 cores, 1 groups`，即没有把处理器拆成多个 k 点并行组；
- VASP 警告表明当前默认 `NCORE=1` 可能不是该节点的最佳并行布局；
- 冷启动没有读取 WAVECAR，第一轮电子自洽通常最慢；含 H 缺陷也可能比高对称纯 Zr更难收敛。

因此“师兄的类似计算很快”与本次慢并不必然矛盾；对方可能使用更稀的 k 点、更宽松的
电子精度、`LREAL=Auto`、合适的 `NCORE/KPAR`、可复用 WAVECAR、不同核数或不同超胞。
只有输入和硬件相同，墙时才可直接比较。

## 11. 第一批结束后的验收与能量定义

四个父作业全部进入终态后，从服务器项目根目录执行：

```bash
cd /work/home/liuzhixiao/Zr-ckj
bash 07_h_diffusion_quickstart/tools/check_initial.sh
```

脚本将检查：

- `General timing and accounting` 正常结束标志；
- 电子达到 `EDIFF`；
- relax 出现 `reached required accuracy`；
- 原子数分别为 96、2、97、97；
- 最后一个 `energy(sigma->0)`；
- relax 最大力不超过约 `0.01 eV/A`。

脚本生成 `01_initial/initial_summary.tsv`，但不会自动判断 T/O 位点身份。还必须比较两份
`CONTCAR` 中 H 的最终分数坐标、最小镜像位移和局部 Zr-H 配位环境。

能量统一使用最终 `energy(sigma->0)`：

```text
Esol(site) = E0[Zr96H(site)] - E0[Zr96] - 1/2 E0[H2]
DeltaE(O-T) = E0[Zr96H(O)] - E0[Zr96H(T)]
```

若 T/O 塌陷到同一位点族，只报告一个实际稳定构型，不虚构两种独立溶解能。若两者均稳定，
选择较低能量者；差值不超过 5 meV 时按既定极简规则选择 T 位作为后续路径起点。
