# 对称端点

本阶段只保留一个几何端点：[`01_tt_c_symmetry/`](01_tt_c_symmetry/)。它不是 VASP 计算目录，
不含 `INCAR`、`KPOINTS`、`POTCAR` 或作业脚本，也不得提交。

## 为什么选择相邻 T2

α-Zr 中 H 的四面体 T 位和八面体 O 位并不是本项目临时发明的标签。Andolina 等的
第一性原理研究讨论了 T/O 的局域结构、四/六配位和位点稳定性；Zhang、Jiang 与 Bai
进一步把最近邻 TT、TO、OT、OO 作为三维扩散网络的基本跳跃，并指出较长的次近邻 TT/OO
路径会分别松弛成 TO+OT/OT+TO。因此本项目先取当前低能 T1 的最近邻 c 向 T 位作为
`TT_c` 终点，同时保留已弛豫 O 作为另一条 `TO` 路径的终点：

- [Andolina et al., *Computational Materials Science* 209 (2022) 111384](https://doi.org/10.1016/j.commatsci.2022.111384)
- [Zhang, Jiang and Bai, *Scientific Reports* 7 (2017) 41033](https://doi.org/10.1038/srep41033)

文献只支持“哪些位点族和基本跳跃值得计算”，并没有提供本项目96-Zr超胞的T2坐标。下面
的具体端点是由本项目晶格、已弛豫T1和可审计的原子置换自行生成的。

## 数学生成方法

T2 由已收敛 T1 末态的全部97个原子经超胞分数坐标操作

```text
S(x,y,z) = (x, y, 7/6-z) mod 1
```

精确生成。理想 T1 `(1/3,5/12,13/24)` 映射到 T2 `(1/3,5/12,15/24)`。理想中心间距
为 `1.29150537 A`；包含两侧对称松弛偏移的实际 H 端点间距为 `1.24144250 A`。

[`01_tt_c_symmetry/symmetry_manifest.tsv`](01_tt_c_symmetry/symmetry_manifest.tsv) 记录源文件
SHA-256、96个 Zr 的一一置换、映射残差、实际/理想位移和配位审计。最大理想映射残差为
`2.8e-15 A`，T2 最近四个 H-Zr 距离为 `2.01772–2.04224 A`，第五近邻为
`3.24342 A`，所以保持清晰四配位。

这里不是只移动H：对称操作先作用于T1末态的全部97个原子，再用理想T-POSCAR确定96个Zr
的一一行置换，所以局域Zr松弛场也随T1一起映射到T2。对同一晶格、元素、赝势、泛函、边界
条件和数值设置，空间对称操作只会把哈密顿量作等价变换，因而

```text
E[S(R)] = E[R]
```

并把T1的力场映射到T2。上述一一映射、近零残差和相同四配位是这项数学等价在当前超胞中的
几何审计。因此NEB两个端点能量都引用已计算的T1
`energy(sigma->0)=-821.95359478 eV`，不额外进行T2 SCF、static或relax；这不是用文献
能量代替本项目计算，也不是假定“看起来对称”。
